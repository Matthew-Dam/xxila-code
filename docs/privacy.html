PRIVACY POLICY

Effective 8 November 2026 · applies to X.X.I.L.A. C.O.D.E on Windows (including the Microsoft Store version), macOS and Linux, and to this website.

THE SHORT VERSION

X.X.I.L.A. C.O.D.E has no accounts, no analytics and no tracking. Xxila-Tech does not receive your code, your files or any information about how you use the app. The app only connects to the internet when you use a feature that needs it, and only to the service that feature names.

DATA STORED ON YOUR COMPUTER

  • Settings, layout, snippets and installed extensions, stored in the app's data folder on your computer.
  • Time Machine history: copies of files you save, kept locally so you can restore earlier versions.
  • AI provider API keys you enter, encrypted with your operating system's secure storage (Windows DPAPI, macOS Keychain, or the Linux secret service).
  • System monitor readings (CPU, memory, network) shown in the HUD are read live and are not saved or sent anywhere.

All of this lives in one data folder: %APPDATA%\XXILA-CODE on Windows, ~/Library/Application Support/XXILA-CODE on macOS and ~/.config/XXILA-CODE on Linux. Deleting that folder removes it. Uninstalling the Microsoft Store version removes it automatically.

WHEN THE APP USES THE INTERNET

  • AI assistants (optional). If you configure an AI provider (for example Anthropic, OpenAI, Google Gemini, Mistral, Groq, OpenRouter, DeepSeek, xAI or Together) and send a request, the app sends your prompt and the code or files you choose to include directly to that provider, using your own API key. That provider's privacy policy applies. Local providers (Ollama, LM Studio) keep everything on your computer. Nothing goes through Xxila-Tech.
  • Extension marketplace (optional). Browsing or installing extensions contacts open-vsx.org, or github.com when you install from a GitHub link.
  • Update check. Once a day the app asks api.github.com whether a newer version exists. Only a standard web request is made, which GitHub sees like any website visit (your IP address). No personal data or usage information is sent. You can turn this off in Settings. The Microsoft Store version doesn't do this; the Store handles updates.
  • Tools you run. Commands you run in the terminal, and helper buttons that install tools such as language servers, Arduino CLI or Python packages, connect to the sites those tools use (for example pypi.org, npmjs.com or github.com).
  • Plugins. A plugin can only access the network if you grant it that permission when prompted.
